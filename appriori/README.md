# Sentiment Analysis — Full Stack (ML + API + Frontend + PostgreSQL + Power BI)

A classical NLP sentiment classifier (**TF-IDF + Logistic Regression**) trained on the NLTK Movie Reviews corpus, served through a **FastAPI** backend, with a lightweight **HTML/JS frontend**, prediction logging to **PostgreSQL**, and a **Power BI** dashboard built on top of that data.

## Architecture

```
Browser (frontend/index.html)
        |
        v
FastAPI (app/main.py) --- loads sentiment_model.joblib
        |
        v
PostgreSQL (predictions table)
        |
        v
Power BI Desktop (DirectQuery / Import) --- dashboard
```

## Setup

```bash
git clone https://github.com/<your-username>/sentiment-analysis-nlp.git
cd sentiment-analysis-nlp

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 1. Start PostgreSQL
```bash
docker compose up -d
```
This starts Postgres on `localhost:5432` with database `sentiment_db` (user `postgres`, password `password`, as set in `docker-compose.yml`). Adjust `.env` if you're using your own Postgres instance instead.

```bash
cp .env.example .env
```

### 2. Train the model
```bash
python sentiment_analysis.py
```
Trains on the NLTK movie reviews corpus and saves `sentiment_model.joblib` in the project root (used by both `predict.py` and the API).

### 3. Run the API + frontend
```bash
uvicorn app.main:app --reload
```
- Frontend: http://localhost:8000
- API docs (Swagger, auto-generated): http://localhost:8000/docs

Every prediction made through the UI or API is written to the `predictions` table in PostgreSQL automatically — no extra setup needed, SQLAlchemy creates the table on first run.

### 4. Build the Power BI dashboard
See [`powerbi/POWER_BI_SETUP.md`](powerbi/POWER_BI_SETUP.md) for the full walkthrough: connecting Power BI Desktop to PostgreSQL, suggested visuals (sentiment split, confidence distribution, predictions over time), and example DAX measures.

> Note: a `.pbix` file itself can't be generated by code — it's a proprietary Power BI Desktop format — but the guide gets you to a working dashboard in a few minutes once the table has data in it.

## API Reference

| Endpoint | Method | Description |
|---|---|---|
| `/predict` | POST | `{"text": "..."}` → returns sentiment, confidence, logs to DB |
| `/predictions?limit=20` | GET | Recent prediction history |
| `/health` | GET | Service + model status check |

## CLI Usage (no API/DB needed)
```bash
python predict.py "This movie was absolutely fantastic!"
```

## How It Works

1. **Training** (`sentiment_analysis.py`) — cleans and vectorizes 2,000 labeled movie reviews with TF-IDF, trains Logistic Regression, evaluates it, and saves the pipeline.
2. **Serving** (`app/main.py`) — loads the saved pipeline once at startup; every `/predict` call cleans the input the same way as training, gets a prediction + confidence, and logs it to PostgreSQL.
3. **Frontend** (`frontend/index.html`) — a single static page with no build step; calls the API directly with `fetch()`.
4. **Storage** (PostgreSQL) — every prediction becomes a permanent, queryable record — this is what makes the Power BI dashboard possible without any extra ETL work.
5. **Reporting** (Power BI) — connects directly to the same `predictions` table for live or scheduled dashboards.

## Possible Extensions

- Add authentication to the API before any real deployment (CORS is wide open for demo purposes)
- Swap Logistic Regression for a Transformer model (e.g. DistilBERT) and compare
- Add a `/predictions/export` CSV endpoint as an alternative Power BI data source
- Containerize the FastAPI app itself (`Dockerfile`) alongside the existing Postgres compose service
- Add pagination/filtering to `/predictions` for larger datasets
